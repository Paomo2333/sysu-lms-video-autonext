# 中大助教培训视频自动连播

这是一个仅用于中山大学在线教学平台指定助教培训课程的小型 Edge/Chrome 扩展。

作用：

- 每个课程视频打开后立即静音，并在播放过程中持续保持静音。
- 当前视频自然播放结束后，等待 4 秒让平台保存观看进度。
- 自动打开页面底部官方“下一节 ►”链接。
- 进入下一页后尝试自动播放；若浏览器拦截，会提示手动点击一次播放。
- 页面不在前台时不会自动切换。
- 不修改倍速，不伪造播放时长，不绕过切屏或焦点检测。

## 安装方法（Edge）

1. 在 Edge 地址栏打开 `edge://extensions/`。
2. 打开左侧的“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择整个 `sysu-lms-video-autonext` 文件夹。
5. 返回课程视频页，刷新一次页面。

安装完成后，页面右上角会出现“自动连播与静音已启用”的绿色提示。

## 使用方法

1. 打开助教资格培训课程中的任意视频。
2. 如果浏览器没有自动播放，手动点击一次播放器的“播放”；视频仍会保持静音。
3. 保持课程页在前台。视频自然结束后会自动进入下一节。

## 停用或删除

完成培训后，打开 `edge://extensions/`，关闭或删除“中大助教培训视频自动连播”即可。

## 文件说明

- `manifest.json`：扩展配置，只允许在中大 LMS 的视频资源页运行。
- `content.js`：强制视频静音，监听视频结束并跳到官方下一节链接。

本扩展不上传数据，也不读取账号密码。
